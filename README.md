Virus Lab

Project Description
Virus Lab is a C++ console-based simulation game. The player will experiment with fictional viruses and observe their effects on NPCs.

## Current Progress
- Created the initial game menu.
- Configured the project to compile and run in Visual Studio.
- Started the development of the NPC display feature.

Planned Features
- Create different virus types.
- Add virus effects and combinations.
- Simulate infections spreading between NPCs.
- Add NPC containment.
- Track outbreak statistics.

Technologies
- C++
- Visual Studio
- GitHub

Development Status
This project is still in development. The virus system and infection simulation are planned features and are not implemented yet.
